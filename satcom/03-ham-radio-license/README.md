# Module 03 — Amateur Radio Licensing

## Learning objectives

- Pass the Technician-class amateur radio exam, which is the legal gate for
  any transmit-based lab in this curriculum and for amateur satellite
  operation (AMSAT, SatNOGS uplink work).
- Come out the other side actually understanding the regulatory and safety
  material, not just having memorized the question pool.

## Prerequisites

None — this can start on day one and run in parallel with Modules 01/02.

## Resources

- **ARRL Ham Radio License Manual** — the standard study guide for the
  Technician exam; explains the material rather than just listing questions.
- **hamstudy.org** — free question-pool practice with spaced repetition;
  effective for closing the gap right before sitting the exam.
- **ARRL / VEC (Volunteer Examiner Coordinator) exam session finder** —
  most areas have regular in-person or remote exam sessions run by local
  ham clubs; a quick web search for "ham radio exam session near me" or
  checking the ARRL's exam session finder will surface options.

## Path

1. Work through the ARRL License Manual once, focusing on understanding
   (not memorizing) the regulatory, safety, and basic electronics sections —
   these overlap directly with Modules 01/02.
2. Drill the question pool on hamstudy.org until you're consistently scoring
   above the passing threshold on practice exams.
3. Sit a Technician exam session (in-person sessions are common and cheap,
   often $15 or less).
4. Optional but worth doing eventually: **General class** license, which
   opens HF privileges — relevant if shortwave/HF propagation work becomes a
   bigger part of your interest later, since Technician alone is mostly
   VHF/UHF plus a few narrow HF slices.

## Why this matters for SATCOM specifically

A Technician license unlocks:
- Legal transmission on VHF/UHF amateur bands, which is what most active
  amateur satellites use for their uplinks.
- Participation in **AMSAT** (amateur satellite organization) and
  **SatNOGS** (open-source satellite ground station network) — both are
  legitimate ways to do real uplink/downlink work with actual satellites,
  not just simulations.
- Legal operation of a TX-capable SDR (HackRF, Tier 2 hardware) on ham
  bands, which several later labs assume.

## Checkpoint

You hold a Technician-class license (or better). This is a binary
checkpoint — either you have the license or you don't, and TX-based labs
elsewhere in this repo assume you do.
