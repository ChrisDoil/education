# Forensics

Parent directory for this repo's forensics curricula. Each subdirectory is
a fully self-contained, independently sequenced curriculum with its own
`README.md` (scope, legal/ethics note, module list, suggested sequencing).

```
windows/   Windows DFIR & Anti-Forensics/Evasion Curriculum
mobile/    Mobile Device Forensics Curriculum (Android + iOS)
```

There's no required order between the two tracks — pick based on which
platform you want to build investigator skill on first.
