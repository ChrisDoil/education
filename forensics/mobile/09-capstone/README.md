# Module 09 — Capstone

## Learning objectives

- Run a full, self-directed multi-device mobile forensics investigation end
  to end: acquisition → artifact analysis → cross-device/cloud correlation
  → timeline → structured technical findings write-up.
- Validate your own methodology with dual-tool verification (confirm key
  findings with at least two independent tools/techniques) — the
  professional standard this entire curriculum has been building toward.

## Prerequisites

Every prior module.

## Resources

None new — this module is synthesis, not new material.

## Hands-on labs

1. Design your own scenario (e.g., "reconstruct this synthetic subject's
   activity across their Android phone, iPhone, and cloud accounts over a
   2-week window") using only known-answer data you control end-to-end.
2. Acquire every device/account involved using the least-invasive method
   that still captures what you need, per Module 02/03's judgment call.
3. Analyze and build one merged timeline across all sources, applying the
   artifact and app-forensics techniques from Modules 04–07.
4. Run an MVT/stalkerware-indicator sweep as a standard part of your
   process, per Module 08.
5. Validate at least 3 key findings using two independent tools or manual
   techniques each, and note explicitly where they agreed or disagreed and
   why.
6. Write a structured technical findings report — what you found, how you
   found it, and how you'd defend the methodology if challenged — as
   practice for the kind of documentation real casework demands.

## Checkpoint

Could you hand your capstone report to someone else and have them
independently verify your key findings from your documented methodology
alone? If yes, you're at the technical competency level this curriculum was
built to reach.
